# 培训一句话阐述

## 完整版（一句话）

团队觉得AI不好用，根源不是工具差，而是协作流程没跑通——这次培训通过**"任务定义→幻觉识别→辨证评论→输出验收"4步流**，教会大家和AI磨出属于自己的协作方法论；课后每人按岗位选一个真实任务走完4步流并截图交作业，后续每月用**"完成时间、一次通过率、方法论版本"**三个指标评估AI对个人业务的效率提升。

## 拆解版（4个短句）

| 维度 | 一句话 |
|:---|:---|
| **我发现的问题** | 团队觉得AI不好用，本质是协作流程没跑通，不是工具不够好。 |
| **培训解决什么** | 通过4步流教会大家和AI磨出个人协作方法论，让AI从"不好用"变成"能帮我干活"。 |
| **交作业** | 每人按岗位选一个真实任务，0-1走完4步流，截图对话过程，沉淀私有协作方法论。 |
| **后续工作流** | 每月用"完成时间、一次通过率、方法论迭代版数"评估AI对个人业务效率的提升。 |
