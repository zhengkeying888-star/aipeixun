# 5月内部AI赋能培训框架

> **培训对象**：私域运营团队
> **培训形式**：1场，约2小时，PPT演示 + 现场实操
> **培训原则**：不讲技术原理，只讲"怎么用"；不聊Agent架构，只聊"按哪个按钮、输入什么话"
> **核心目标**：让团队从"AI不好用"到"AI能帮我干活"

## 二、PPT内容大纲（8-10页）

### PPT第1页：开场 — AI赋能实战培训
- 标题：AI赋能实战培训 — 让AI帮你干活
- 副标题：私域运营团队 · 2026年5月
- 核心认知：AI是协作工具，不是替代者

### PPT第2页：AI的现状痛点 — 不只是"不好用"
- 团队真实状态：AI输出跑偏了，第一反应是"骂AI"
- 核心真相：任务定义没做好，再贵的模型也救不了
- 3大模型病（不可避免）：
  ① AI失忆 — 上下文有天花板（DeepSeek长对话后遗忘）
  ② AI胡说 — 幻觉是模型固有缺陷（连Gemini也会）
  ③ AI重复 — 输出同质化，角度单一
- 根本解法：不是换更贵的模型，是学会和AI协作（任务定义→幻觉识别→辨证评论→输出验收）

### PPT第2页：基础入门 — 提示词核心公式
- 核心公式：你是谁 + 做什么 + 输入什么 + 输出格式
- 坏提示词示例 vs 好提示词示例（结构对比，不含完整真实模板）
- 关键差异：身份、画像、动作、要求、违禁词、框架

### PPT第3页：进阶方法 — 系统模板6要素
1. 【身份】你是谁
2. 【用户画像】不变的用户特征
3. 【动作】你每次让AI做什么
4. 【输出要求】固定的格式约束
5. 【违禁词清单】固定不能出现的词
6. 【参考框架/示例】文案结构或复盘结构

### PPT第4页：进阶方法 — 各自任务定义方法论

**左栏：文案攥写任务定义**
- 适用场景：信息流文案 / 数字人脚本 / 直播预热
- 任务定义6步：确定文案类型 → 明确用户画像 → 定义输出格式 → 列出违禁词 → 提供参考框架 → 定义本次变量
- 核心原则：一对话一任务；主模板（身份+画像+违禁词）+ 子模板（各场景格式约束）

**右栏：数据复盘任务定义**
- 适用场景：新用户策略复盘 / 素材推送复盘 / 直播回捞复盘
- 任务定义6步：确定复盘类型 → 明确数据周期 → 定义核心指标 → 列出分析维度 → 提供分析框架 → 定义输出格式
- 核心原则：把"分析思路"写进模板，让AI按你的逻辑跑数据

### PPT第5页：进阶方法 — 加载方式3选1
- 方式A（小白推荐）：DeepSeek — 日常主力，文案/复盘/策略，人人可用
- 方式B（进阶推荐）：Gemini 5.5 — 支持多模态，长文本分析，需安全翻墙
- 方式C（超级进阶推荐）：Cursor / Claude Code / Codex — 工作流自动下发执行，高阶自动化

### PPT第6页：进阶方法 — 4个常见问题与解决方案

| 问题 | 真实场景 | 解决方案 |
|:---|:---|:---|
| AI失忆 | 写了10轮后，AI忘记不能出现"健康""养生" | 每次新对话先加载模板；10轮后主动开新对话 |
| AI胡说 | AI突然推荐了一个不存在的课程 | "如果不确定，写'不确定'"；输出后自检违禁词 |
| 千篇一律 | 连写5条文案，AI都是"腰酸背痛"开头 | 角度库法：每次从悬疑类/互动类/大众兴趣类中轮换 |
| 不会纠正 | AI理解偏差，运营不知道怎么说 | "不对，我不是问A，而是问B""这个方向雷同，换一个" |

### PPT第7页：进阶方法 — 数据复盘方法论

**上半部分：新用户策略数据复盘**
- 分析漏斗：注册 → 首课 → 留存 → 跨科 → 领课
- 核心问题：找出哪个环节变化最大、为什么、下周优化动作
- 案例：唱歌宋5.4直播回捞（真实数据对比）

**下半部分：素材推送数据复盘**
- 核心指标：推送人群数、点击率、转化率、访购率、素材类型（1v1/朋友圈/社群）
- 核心问题：本周vs上周哪类素材效果好、为什么、下周换什么素材
- 案例：普拉提4.27回捞触达率（Agent vs 人工对比）

**通用提示词框架（讲师拆解，学员记笔记）：**

- 整体转化率（分母：新量）：X%
- day7跨科率：X%
- day7开口率：X%

【上周数据】
...

【回捞动作说明】
...

【品类用户画像】
- 年龄层：
- 学习动机：
- 核心痛点：
- 决策顾虑：

任务：
1. 对比本周vs上周，哪个环节变化最大？可能原因？
2. 结合用户画像，分析关键指标变化的原因
3. 给出1个下周可立即执行的优化动作（具体：改什么、怎么改、预期效果）

### PPT第8页：实战指引 — 步骤1 制作个人系统模板
- 确定核心任务（3选1）：① 文案攥写 ② 数据复盘 ③ 豆包生图
- 填写6要素（用空白框架示意，学员自己填）
- 选择加载方式
- 用AI测试

### PPT第9页：实战指引 — 步骤2 双轨实操二选一
- 轨道A：文案攥写（打开新对话→加载自己建的模板→输入变量→AI输出→纠正优化）
- 轨道B：数据复盘（自己整理数据对比表→粘贴提示词框架→粘贴真实数据→AI分析）
- **说明**：轨道A和轨道B都是必学内容，实战环节二选一现场产出

### PPT第10页：总结 — 4件事回顾 + 进阶工具推荐
- ① 系统模板解决AI失忆
- ② 输出约束解决AI幻觉
- ③ 纠正话术解决AI跑偏
- ④ 数据复盘形成习惯
- 工具推荐：DeepSeek「技能」/ Gemini（需安全翻墙）/ 豆包生图 / Claude Code

## 三、培训现场流程（2小时）

### 板块一：认知破冰（15分钟）
- 用小李的故事开场
- 明确AI是"高效执行员"，不是"创意总监"
- 说明今天能带走什么

### 板块二：基础入门（20分钟）
- 讲解核心公式（5分钟）
- 现场演示文案好坏对比（10分钟）——讲师用真实案例投屏演示
- 学员跟练：每人按公式写一段提示词开头（5分钟）

### 板块三：进阶方法（25分钟）
- 系统模板6要素讲解（10分钟）
- 加载方式3选1演示（5分钟）——重点演示DeepSeek「技能」
- 4个解决方案讲解（10分钟）——用真实案例投屏演示

### 板块四：实战演练（45分钟）
- 步骤1：制作个人系统模板（15分钟）——学员自己写，组长巡视
- 步骤2：双轨实操二选一（15分钟）——学员用DeepSeek现场操作
- 步骤3：分享点评（15分钟）——抽3-4人展示，现场点评

### 板块五：总结与进阶（5分钟）
- 4件事回顾
- 进阶工具推荐
- 5月使用计划（口头讲解）

## 四、讲师演示案例（投屏用，不留在PPT页面上）

### 案例1：文案攥写 — 中老年课程营销文案

**坏提示词**：
```
帮我写一条推销课程的文案
```

**好提示词结构**（讲师现场拆解，学员记笔记）：
- 【身份】你是谁
- 【用户画像】不变的用户特征（年龄段、已购课程、需求）
- 【动作】推广什么、输出什么
- 【输出要求】段数、字数、类型、emoji位置
- 【违禁词清单】不能出现的词（放在最前面）
- 【文案框架】首段/第二段/末尾分别写什么
- 【文案风格】弱营销、像朋友推荐
- 【本次变量】课程名称、卖点、季节（每次只改这里）

**讲师演示流程**：
1. 加载系统模板（DeepSeek技能或粘贴）
2. 输入变量：课程=五禽戏调理营，卖点=传承人亲授，季节=冬季养腰
3. AI输出文案
4. 要求换角度（从悬疑类换成互动类）
5. AI换角度输出
6. 演示纠正话术：AI跑偏后一句话拉回正轨

## 五、平台分工建议

| 平台 | 使用场景 | 适合人群 | 备注 |
|:---|:---|:---|:---|
| **DeepSeek** | 日常主力：文案攥写、数据复盘、策略生成 | 全员 | 不翻墙、免费/低价、中文理解好。支持「技能」功能。培训现场统一使用。 |
| **Gemini** | 进阶补充：长文本分析、复杂多维度推理 | 有安全翻墙条件的运营 | 上下文窗口大。需安全翻墙方式（IT统一配置或可靠付费服务），禁止免费VPN。 |
| **豆包** | 生图专用：课程表、海报、直播预告图 | 需要制作图片的运营 | 国内可用，适合中老年审美。 |
| **Claude Code** | 高阶自动化：批量处理Excel、自动生成报告 | 技术好奇心强的运营 | 需安装VS Code插件，通过自然语言指挥AI写代码。 |

**翻墙安全建议**：
- 禁止使用：来路不明的免费VPN/加速器（极易携带病毒木马）
- 推荐方式：① IT部门统一配置企业级VPN；② 购买可靠的付费翻墙服务；③ 使用开源工具（Clash/V2rayN等）并从GitHub官方仓库下载
- 5月培训以DeepSeek为主（人人可用），Gemini作为"有安全翻墙条件的运营自行探索"选项

## 六、培训后跟进机制

| 时间 | 动作 | 检查标准 |
|:---|:---|:---|
| **培训当天** | 每人提交1份《个人系统模板》+ 1份实操产出（文案或数据复盘） | 系统模板6要素完整，产出符合模板约束 |

| **每周五** | 数据/策略运营固定30分钟做AI数据复盘 | 每周五下班前群里发复盘截图 |
| **每周** | 每人迭代1次系统模板（根据AI输出效果优化） | 月底对比初版vs终版，看优化点 |
| **5月末** | 每人提交《个人系统模板终版》+ 1份数据复盘报告（或3条AI文案+纠正记录） | 统计培训前后：AI使用率、文案产出效率、数据复盘完成率 |

## 七、6大核心痛点与解决方案速查

| 痛点 | 真实场景 | 解决方案 |
|:---|:---|:---|
| AI失忆 & 重复输入 | 每次写文案都要贴一遍背景，长对话后AI失忆 | 「系统模板」+ 自动加载（DeepSeek技能/快捷短语） |
| AI幻觉 & 输出失控 | AI偶尔失灵、胡说、违禁词漏掉 | 「输出约束」三板斧：违禁词放最前面 + 自检指令 + 纠正话术 |
| 输出同质化 & 深度不足 | 同一个提示词多次使用，AI输出雷同 | 「角度库 + 参考示例」：内置角度库、场景化痛点库、参考文案 |
| 多场景切换混乱 | 信息流/数字人/直播预热格式不同，切换时AI混乱 | 「主模板 + 子模板」+ 严格遵守"一对话一任务" |
| AI能力边界不清 | 想让AI给策略框架、产出成品文案 | 明确边界：策略框架靠人，执行细节靠AI |
| 工具使用与安全问题 | 免费VPN翻墙中毒、豆包生图不会写提示词 | 禁止免费VPN，由IT统一配置；掌握豆包生图三要素 |

## 八、内部赋能AI与5月绩效对齐

| 绩效板块 | 培训对应内容 | 5月落地节奏 |
|:---|:---|:---|
| 品类用户画像（Week 1-2） | 系统模板中的【用户画像】要素 | 培训当天起，每人开始收集自己品类的用户原声 |
| 用户分层与需求提炼（Week 2-3） | 在系统模板中积累《用户分层速查表》 | 每天用AI给1-3个用户打标签 |
| 日常大课数据复盘（Week 3-4） | 培训中的数据复盘双轨（轨道B） | 每周五固定30分钟做AI数据复盘 |
| 新用户策略数据复盘 | 按周期分析转化漏斗 | 结合绩效中的留存指标同步进行 |
| 策略生成 | 基于洞察+数据，AI生成行动清单 | 每周五复盘后输出下周行动策略 |
