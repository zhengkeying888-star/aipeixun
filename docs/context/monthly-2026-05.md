# 2026年5月绩效目标与里程碑

## 定量指标（60%）

### 营收业绩（50%）

#### 整体公海目标（20%）
- **GMV**：210w（0.8档 168w / 1.2档 252w / 1.5档 315w）
- **新用户首周 day7 跨科率**：2.29%
- **day14 领课率**：3.43%
- **策略**：首跨分层 + 次跨分层，提升新用户首周跨科率和领课转化

#### 总体直播组目标（20%）
- **直播间产值**：90w（0.8档 72w / 1.2档 108w / 1.5档 135w）
- **数字人-孵化品支持计划直播间转率**：5%
- **策略**：新增数字人直播降低孵化品冷启动成本；旧指标（复用率≥30%、新用户策略直播场次占比）彻底下线

#### 整体APP商业化目标（10%）
- **APP 产值**：230w（0.8档 184w / 1.2档 276w / 1.5档 345w）
- **策略**：扩品放量后进入 CTR 优化阶段，优化素材质量和分层漏斗；稳固导量 = 资源位 × 品类分配规则

### 留存（10%）

#### 公海转继承新用户首周留存率（5%）
- **day7 留存率**：92.24%（0.8档 73.79%，不设高线档位）
- **观测样本**：MVP 品类（唱歌宋），因尚未完成全品类扩品
- **策略**：agent 覆盖提升运营效率，abtest 对比 agent 与人工差异归属 AI 板块

#### APP月活用户数（5%）
- **MAU**：80w（0.8档 64w / 1.2档 96w / 1.5档 120w）
- **策略**：私域引流与 day15 新用户运营结合，提升 APP 下载率和登录率

## 定性指标（45%）

### 留存（10%）

#### 转继承新用户 day15 营销规划（10%）
- **全周期目标**：
  - day15 留存率 90%（基准值 86.07%，提升 6%）
  - day14 跨科率 4.0%（基准值 3.73%，提升 8.11%）
  - 5 月前跑通 3 个品类
- **MVP 验证（唱歌宋）**：
  - day14 领课率 2.5%（基准值 2%，提升 25%）
  - day15 留存率 90%（基准值 87.39%，提升 3%）
- **策略**：落地「趣小导」分层营销；企微私域 + APP 学习阵地 + H5 三线并行；游戏化打卡 + 跨科认知建设；学分商城激活协作融入

### AI（25%）

#### 新用户 agent（10%）
- **覆盖率**：>50%，数据维稳
- **策略**：规模化覆盖；优化场景化运营节点；直播域名提升转化留存；abtest 验证 agent vs 人工效果

#### 直播中价课-MA打通（5%）
- **目标**：复用至公海 S 级中价课营销，进入放量验证
- **策略**：MA 全链路自动化（人群圈选→触达→转化→复盘）；测试 399 元和 199 元中价课（健康线）

#### 内容策略Agent（10%）
- **目标**：扩品并内容下发规模化
- **策略**：保障下发稳定性；流程化管理降低重复性；视频素材对接产研（非 5 月 KPI，长期储备）

### APP商业化规划（5%）

#### 资源整合（5%）
- **目标**：看板常态化 + 资源分配规则梳理完成
- **策略**：
  1. 优化分析模块，完成 5 月月报分析 HTML，形成周/月常态化监控
  2. 梳理 APP 资源分配规则（成熟品-孵化品-新上线孵化品曝光-导量逻辑），输出规则文档并推动落地

### 内部赋能（5%）

#### 内部赋能 AI（5%）
- **目标**：完成 2-3 个重点品类的 AI 用户画像 + 数据复盘；输出《用户洞察与数据复盘 AI 赋能手册》；每个运营按模板完成至少 1 次个人品类的周度数据复盘
- **策略**：建立「洞察 → 分析 → 行动」个人运营闭环：
  1. **品类用户画像**（Week 1-2）：收集 10-20 条用户原声，用 AI 归纳品类用户特征（年龄层、学习动机、核心痛点、决策顾虑）
  2. **用户分层与需求提炼**（Week 2-3）：每天用 AI 给 1-3 个用户打标签、提炼需求，积累《用户分层速查表》
  3. **日常大课数据复盘**（Week 3-4，每周五）：输入推送用户人群、访购率、例子数、点击率、转化率等数据，AI 对比本周vs上周，分析变化原因，结合用户洞察给出下周行动策略
  4. **新用户策略数据复盘**：按周期分析新用户转化漏斗（注册→首课→留存→跨科→领课），找出卡点并输出优化建议
  5. **策略生成**：基于洞察+数据，AI 生成下周具体行动清单（做什么、为什么、预期效果）
- **标杆案例**：3 个品类的完整案例（画像 → 分层 → 数据复盘 → 行动策略）
- **档位**：1.0 档 = 手册完成，每人完成 1 次完整的数据复盘；1.2 档 = 团队应用后数据指标提升或案例被复用

#### 培训执行调整（本轮确认）
- **培训形式**：1场约2小时，PPT演示 + 15分钟当场实操，不发放含真实模板的纸质材料
- **核心方法**：人机协作4步流（任务定义 → 幻觉识别 → 辨证评论 → 输出验收），不是教提示词模板，是教协作方法论
- **任务定义方法论**：不是填模板，是和AI对话4+轮，从模糊磨到清晰，最终沉淀个人协作SOP
- **当场实战（第17页）**：替换原答疑环节，学员带上自己原先的任务，现场跑一次4步流，体验工作流变化
- **工具分层**：以DeepSeek（免费）为主力，Gemini/Cursor作为进阶选项；诚实面对所有AI的幻觉问题
- **作业设计**：按岗位角色差异化——文案运营（信息流/数字人/直播预热）、数据运营（直播回捞/素材推送复盘）
- **月度评估指标**：完成时间、一次通过率、方法论迭代版数
