## 档位机制

### 定量指标档位
基础目标 = 1.0 档，按线性折算：
- 0.8 档 = 目标值 × 0.8
- 1.0 档 = 目标值
- 1.2 档 = 目标值 × 1.2
- 1.5 档 = 目标值 × 1.5

**特殊规则**：留存率类指标（天然有天花板）不设高线档位（1.2/1.5），仅保留 1.0 档和 0.8 档。

### 定性指标档位
- 1.0 档：项目/功能上线并达标
- 1.2 档：超额达标（效果显著优于预期）
- 不设 0.8 档和 1.5 档

## 旧指标处理规则

旧指标弱化后**彻底下线**，不再出现在后续月份绩效中。如需恢复，需重新作为新项目论证并纳入。

## MVP品类观测规则

未扩品阶段，留存类指标以 MVP 品类为观测样本。完成全品类扩品后，次月切换为全品类考核。

## APP资源分配规则

资源分配规则文档（成熟品-孵化品-新上线孵化品的曝光-导量规则）作为后续月份资源位运营的基础依据，后续调整需更新文档版本。
