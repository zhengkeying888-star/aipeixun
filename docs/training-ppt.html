工具真相 — LLM 和 AGENT 是两回事

先分清维度，再选工具；所有模型都会幻觉

💬

LLM（大语言模型）— 对话生成

你输入文字，它生成文字。像高级搜索引擎+写作助手。

DeepSeek

优点：不翻墙、中文好、免费
缺点：长对话失忆、幻觉不可避免

豆包

优点：国内可用、生图适合中老年审美
缺点：文本推理弱、同样会幻觉

Gemini 3.1 Pro

优点：上下文大（100万token）、多模态
缺点：需翻墙、复杂推理仍翻车、也会幻觉

GPT-5.5 / ChatGPT

优点：推理强、功能全、生态成熟
缺点：付费、幻觉减少但未消除

🤖

AGENT（智能体）— 自动化执行

你描述目标，它自动操作文件/写代码/执行流程。像实习生。

Cursor

优点：直接改代码、操作文件、$20/月
缺点：需配置环境、学习成本高

Claude Code

优点：命令行AI、批量处理、自动化强
缺点：需VS Code环境、英文为主

Trae Solo（推荐）

优点：字节跳动出品、免费、内置模型、国内直连不用翻墙、有每日额度次日重置
缺点：大项目代码质量略弱、可能过度自动化

📌 关键认知 1：LLM 和 AGENT 不是升级关系，是不同维度

LLM 是"大脑"，AGENT 是"大脑+手脚"。AGENT 底层也是 LLM，但它会自己操作电脑。

⚠️ 关键认知 2：没有AI不会幻觉，只有协作流程能降低损失

DeepSeek会、Gemini 3.1 Pro会、GPT-5.5也会。AGENT也会操作错文件。

Step1 任务定义 — 文案场景

明确对象、类型、目的、输出、边界、约束、标准。不是填模板，是和AI对话磨到清晰

任务定义 = 对象（推什么课）+ 类型（文案/复盘）+ 目的（引导领课）+ 输出（格式/字数）+ 边界（不能说什么）+ 约束（违禁词/风格）+ 标准（可直接下发）

帮我写条短视频文案

亲爱的用户，我们的课程非常专业，老师经验丰富，快来报名吧！
🙋 运营（第2轮）
不对，我是中老年课程运营，用户是50-60岁已购八段锦人群，帮我推五禽戏体验课
🤖 AI
五禽戏是华佗发明的养生功法，可以调理身体，欢迎大家报名体验...
🙋 运营（第3轮）
要弱营销，120字以内，不能出现"健康""养生""中医"，像朋友推荐
🤖 AI
😣 冬天洗碗站一会儿腰就酸...
👍 我最近跟着传承人练了套五禽戏...
💪 这次老师把"熊运""鸟伸"单独拎出来...
👉 老学员专属，仅50个免费学名额...
🙋 运营（第4轮）
刚才4轮试下来，我总结一下我和AI协作写文案的SOP：①先交代身份+用户画像 ②再列违禁词（放最前面，不然你会忘）③给一条参考文案定风格 ④最后给本次变量。你确认下这个顺序对吗？有没有我漏掉的关键环节？
🤖 AI
✅ 确认。你的文案协作路径已梳理：身份画像 → 违禁词 → 参考定调 → 变量输入。补充建议：如果变量含「季节/热点」，可在第③步后加一句「结合当下场景」，帮助AI更精准关联。这套流程是你和AI磨合出来的个人协作方法论，下次可直接按此顺序发起。

🎯 第4轮终点：不是产出一条文案，是磨出属于你自己的AI协作SOP

🙋 运营（第3轮）

变化最大：预约率降34.97%。原因：新增用户质量下降+预告文案吸引力不足。优化动作：1v1回捞从"催促买课"改为"邀请进群+推荐兴趣课"
🙋 运营（第4轮）
我总结数据复盘SOP：①品类+画像 ②本周vs上周数据 ③分析任务（变化最大+原因+1个动作）④数据不足直说。我不要一堆建议，只要1个落地动作。整理成我的「数据复盘口令」，下次粘贴这段开头，对吗？
🤖 AI
✅ 确认。你的路径：画像定调→数据对比→三问聚焦→落地动作。核心是把「1个动作」作为硬性截止，避免AI泛泛而谈。建议每周五跑一遍，数据积累后加入环比趋势。这套口令是你和AI磨合出来的个人方法论载体。

🎯 终点不是一份复盘报告，是磨出属于你的「数据复盘协作口令」

Step2 幻觉识别

AI输出后，先过一遍这3个信号

📛

事实性幻觉

AI提到了不存在的课程、编造的数据、虚构的政策

🚫 例：AI推荐"五禽戏进阶班"，但公司根本没有这个课
⚠️

约束性幻觉

AI漏掉了你明确要求的违禁词、格式、字数、风格

🚫 例：你说了不能出现"健康"，AI输出里还是有
🧭

方向性幻觉

AI答的不是你问的，理解了偏差

🚫 例：你问"用户动机"，AI答"购买障碍"

识别原则：所有AI都会幻觉，DeepSeek会、Gemini也会。关键不是"换更贵的模型"，是输出后先自检，发现问题再纠正。

Step3 辨证评论

辨认问题 → 指出偏差 → 给出正确方向

🔴 基础版辨证：纠正方向

❌ AI第一次输出（方向幻觉）
老年人购买短视频课的痛点是：操作复杂、信息筛选困难、支付安全...
🙋 运营纠正
不对，我不是问你购买过程中的痛点，而是想知道用户在产生需求时的初始动机和需要解决的问题
✅ AI修正后
动机一：想留住有意义的瞬间，但拍出来不好看...
动机二：想跟上时代，但不知道怎么开始...

🟢 深化版辨证：打磨颗粒度

⚠️ AI修正后（仍太泛）
想留住有意义的瞬间，但拍出来不好看...
🙋 运营深化
这个场景太泛了。我需要像"李奶奶给3岁孙女过生日拍视频，画面抖、光线暗"这种颗粒度，才能写文案
✅ AI最终输出
场景：李奶奶给孙女过生日，手机拍的视频画面抖、光线暗，发到家庭群被女儿说"看不清"...

💡 辨证话术模板："不对，我不是问A，而是问B" → "这个太泛，我需要XX颗粒度"

Step4 输出验收

人为验收，不依赖AI自检。发现问题反哺方法论

📋 人为验收清单

  • 事实核查：课程名/价格/老师名/数据是否准确
  • 违禁词扫描：对照清单逐条过
  • 格式核对：字数/段数/emoji位置
  • 角度去重：与本周已发素材对比
  • 风格把关：弱营销，像朋友推荐
  • 可交付确认：可以直接复制粘贴下发

🔄 反哺方法论

验收中发现的问题，要迭代回任务定义：

📝 例：验收发现AI老是漏掉"养生"这个词

→ 把"养生"从违禁词清单第5条移到第1条

→ 在任务定义里加一句"违禁词按严重程度排序"

核心：每次验收都是一次方法论迭代。你的框架是v1.0 → v1.1 → v1.2
