# AI赋能实战培训 · 课程大纲

> 培训对象：私域运营团队  
> 时长：约2小时（120分钟）  
> 核心目标：让团队从"AI不好用"转变为"AI能帮我干活"  
> 文件：[training-ppt.html](training-ppt.html)（22页）+ [training-script.md](training-script.md)（讲师手册）

---

## 第一层：认知层（Slides 1-6）｜25分钟

### 1.1 开场——运营小李的故事（Slide 2）
- **核心**：为什么你觉得"AI不好用"？
- **痛点**：每天写10条文案、每次贴800字背景、AI失忆跑偏
- **结论**：问题不在AI，在每次都要重新教AI你是谁

### 1.2 AI的三大现状痛点（Slide 3）
- **AI失忆**：长对话后忘记约束，上下文有天花板
- **AI胡说（幻觉）**：推荐不存在的课程、编造数据
- **AI重复**：输出同质化、角度单一
- **核心认知**：三个问题骂AI没用，是协作方式没跑通

### 1.3 AI是高效执行员，不是创意总监（Slide 4）
- **能做**：按框架输出文案、检查违禁词、基于数据做分析
- **不能做**：替代你想出新主题、凭空创作"感觉"
- **核心认知**：策略靠人，执行靠AI

### 1.4 AI基础知识速览（Slide 5）
- **LLM**：读了全网书籍的"猜词机器"→ 给越精准的背景，猜得越对
- **AGENT**：LLM + 手脚 → 能操作文件、写代码
- **为什么运营必须懂**：必须人为验收、精准背景比换模型更重要

### 1.5 工具真相——所有模型都会幻觉（Slide 6）
- **LLM对比**：DeepSeek（免费/中文好/不翻墙）/ 豆包 / Gemini / GPT-4o
- **AGENT对比**：Cursor / Claude Code / Trae Solo
- **关键认知**：LLM和AGENT不是升级关系；没有AI不会幻觉
- **结论**：先把DeepSeek榨干，再考虑换工具

## 第二层：思维层（Slides 7-10）｜20分钟

### 2.1 为什么要拆解——不拆vs拆（Slide 7）
- **不拆**：直接扔一个大任务给AI → 角度瞎猜、卖点编造、违禁词没人管
- **拆了**：人主导+LLM辅助分析需求 → 人+LLM共创角度 → LLM撰写 → LLM自检→人验收 → 人优化
- **核心认知**：不是AI不好用，是你给AI的任务太大了

### 2.2 拿到任务先拆解——两步拆解法（Slide 8）
- **第一步·基础拆解**：不考虑AI，按传统SOP拆步骤（写文案=5步）
- **第二步·进阶拆解→任务分工**：每步问"交给不懂业务的实习生，我放心吗？"
  - 放心 → 给LLM
  - 不放心 → 人做，最多让LLM辅助
- **文案工作流任务分工图**：5步横向流程 + 颜色区分（黄=人/绿=LLM/深绿=共创）
- **数据复盘任务分工**：人整理数据 → LLM找异常+分析原因 → 人决策 → LLM给1个落地动作

### 2.3 一次拆解，各自跑执行闭环（Slide 9）
- **分支模型**：1次拆解 → N个执行闭环
- **拆解阶段**：一次性定义任务分工（产出任务分工图+系统模板）
- **执行阶段**：每个有LLM参与的子步骤，独立对话，反复跑"识别→辨证→验收"循环
- **关键认知**：任务定义一次性完成，识别→辨证→验收反复循环直到交付

### 2.4 协作成果的三层沉淀（Slide 10）
- **第一层（最宽·最复用）**：任务分工图 —— 同类任务复用骨架
- **第二层（中宽·中复用）**：系统模板 —— 同一步骤复用，只换变量
- **第三层（最窄·不复用）**：4步流对话记录 —— 一次性打磨
- **沉淀逻辑**：先跑通对话 → 沉淀为模板 → 沉淀为拆解图

## 第三层：执行层·任务定义（Slides 11-16）｜30分钟

### 3.1 核心公式——一条好文案从会说话开始（Slide 11）
- **公式**：角色 + 背景 + 目标 + 要求 + 约束 = 🎯
- **坏提示词**：只给动作，不给背景 → AI空泛输出
- **好提示词**：5要素齐全 → AI精准输出

### 3.2 系统模板6要素（Slide 12）
- **Constants（不变）**：身份、用户画像、输出要求、违禁词清单、参考框架/示例（few-shot）
- **Variable（每次变）**：动作与变量
- **核心认知**：把不变的信息存起来，每次只改变量
- **落地**：DeepSeek存备忘录/飞书文档；豆包可创建智能体保存

### 3.3 现阶段你的工作流——4步骤（Slide 13）
1. **准备系统模板**（填写6要素）
2. **只改变量**（打开新对话→粘贴模板→输入变量）
3. **跑通4步闭环**（任务定义→幻觉识别→辨证纠正→验收交付）
4. **迭代模板**（验收发现问题→反馈回模板）
- **Before/After对比**：从"每次重新交代背景→AI跑偏→骂AI→手写"到"加载模板→输入变量→4步闭环→验收交付"

### 3.4 方法论打磨对话（Slide 14）
- **方式A**：主动补充背景 → 直接给AI身份+场景+卡点+期望
- **方式B**：让AI反问你 → 通过4轮问答，AI帮你梳理出协作SOP
- **终点**：产出属于你的「任务定义协作口令」

### 3.5 场景实战：文案的任务定义——一步版vs两步版（Slide 15）
- **❌ 一步版**：人只给背景，角度让AI自由发挥 → AI跑偏（贬低已购课程、捏造活动、痛点太泛）
- **✅ 两步版**：
  - Step A（人机共创角度）：AI给3个角度+理由，人选一个
  - Step B（任务定义→4步流撰写）：AI按给定角度执行
- **核心差异**：多一轮对话，质量提升10倍

### 3.6 场景实战：数据复盘的任务定义（Slide 16）
- **差提示词**：渐进修正过程（从模糊到精准）
- **好提示词结构**：画像定调→数据对比→三问聚焦→落地动作
- **硬性约束**："不要一堆建议，只要1个落地动作"
- **终点**：产出「数据复盘协作口令」

## 第四层：执行层·识别/辨证/验收（Slides 17-19）｜20分钟

### 4.1 幻觉识别——三种问题（Slide 17）
- **事实性幻觉**：编造不存在的课程/数据/政策 → 最危险
- **约束性幻觉**：漏掉违禁词、格式、字数 → 最常见
- **方向性幻觉**：答非所问 → 最难发现
- **识别原则**：所有AI都会幻觉，输出后先自检，发现问题再纠正

### 4.2 辨证评论——怎么跟AI说才能改对（Slide 18）
- **基础版·纠正方向**："不对，我不是问A，而是问B"
- **深化版·打磨颗粒度**："这个太泛，我需要XX颗粒度"
- **案例**：从"购买障碍"纠正为"初始动机"，再深化为"李奶奶给孙女过生日，画面抖、光线暗"

### 4.3 输出验收——双重把关（Slide 19）
- **AI自检三步法（前置过滤）**：在任务定义里加自检指令（Reflection Pattern）
  - 生成初稿 → 按清单自检 → 优化输出
- **人为验收清单（最终把关）**：6项检查
  - 事实核查 / 违禁词扫描 / 格式核对 / 角度去重 / 风格把关 / 可交付确认
- **反哺方法论**：验收中发现的问题迭代回任务定义（模板v1.0→v1.1→v1.2）

## 第五层：落地层（Slides 20-22）｜25分钟

### 5.1 下一步：先把基础工具用透（Slide 20）
- **停止死循环**：永远在换LLM，从来不磨流程
- **正确路径**：选一个任务 → 用DeepSeek跑通4步流 → 反复用 → 迭代框架
- **标准**：3个任务都沉淀出框架了，才考虑换工具
- **现在不要做的事**：花钱开付费会员、研究下一个LLM

### 5.2 现场实战——15分钟体验变化（Slide 21）
1. **讲师演示**（2分钟）：展示一个文案任务怎么拆
2. **学员拆解**（3分钟）：打开自己的任务，拆步骤→判分工→自检
3. **跑4步流**（8分钟）：选1个LLM步骤，加载模板+变量→识别幻觉→辨证纠正→验收
4. **分享**（2分钟）：截图发群，晒任务分工图+4步流产出
- **核心体验**：不是"AI帮我写"，是"我和AI磨出了协作方式"

### 5.3 带走什么 & 下一步（Slide 22）
- **带走4张卡**：任务拆解卡 / 任务定义记录卡 / 幻觉识别速查卡 / 辨证评论话术卡
- **本周作业**：按岗位角色选一个真实任务，产出任务拆解图 + 1个步骤的4步流截图
- **每月评估**：4个问题嵌入工作流（能拆清楚吗？时间缩短了吗？一次通过率提高了吗？迭代了几版？）
