# 月度绩效与AI赋能培训项目

> 项目归属：平台运营统筹
> 当前月份：2026年5月

## 目录结构

```
docs/
├── README.md                          # 本文件：入口索引
├── context/                           # 背景资料与上下文
│   ├── background-materials-draft.md  # 背景资料草稿（生命周期管理）
│   ├── monthly-2026-05.md             # 5月绩效目标与里程碑（正式背景）
│   └── performance-framework.md       # 绩效框架长期规则（正式背景）
├── progress/                          # 进度与状态
│   └── current-status.md              # 当前项目状态
├── bugs/                              # 偏差、风险、已知问题
│   └── known-issues.md                # 已知问题与冲突记录
├── outputs/                           # 产出文件（推荐后续新产出放此处）
│   └── (当前散落文件见下方说明)
├── 2026-05-performance-report.md      # 5月绩效报告终稿
├── 2026-05-ai-training-framework.md   # AI赋能培训框架
├── prd-ai-training-2026-05.md         # 培训PRD
├── 2026-05-ai-training-ppt-prompt.md  # PPT生成提示词
├── training-ppt.html                  # 培训演示文稿（18页HTML）
└── training-one-liner.md              # 培训一句话阐述
```

## 文件职责速查

| 文件 | 类型 | 用途 |
|:---|:---|:---|
| `context/performance-framework.md` | 正式背景 | 长期规则：权重分配、档位机制、旧指标/MVP/资源规则 |
| `context/monthly-2026-05.md` | 正式背景 | 5月具体目标、里程碑、风险关注、培训执行调整 |
| `context/background-materials-draft.md` | 草稿 | 背景资料生命周期管理记录 |
| `2026-05-performance-report.md` | 产出 | 5月绩效报告终稿 |
| `prd-ai-training-2026-05.md` | 产出 | 培训需求文档（PRD） |
| `2026-05-ai-training-framework.md` | 产出 | 培训框架：PPT大纲、讲师案例、跟进机制 |
| `training-ppt.html` | 产出 | 18页HTML演示文稿（键盘导航：← → 空格） |
| `training-one-liner.md` | 产出 | 培训一句话阐述 + 拆解版 |
| `2026-05-ai-training-ppt-prompt.md` | 产出 | AI生成PPT的提示词模板 |

## 路由规则

- 新背景资料草稿 → `context/background-materials-draft.md`
- 已确认正式背景 → `context/`（当前），后续推荐 `context/background/`
- 当前状态 → `progress/current-status.md`
- 偏差/风险/复盘 → `bugs/known-issues.md`
- 新产出文件 → `outputs/`
