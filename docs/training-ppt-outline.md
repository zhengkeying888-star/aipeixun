## 第10页：Step1 任务定义 — 文案场景

**标题**：Step1 任务定义 — 文案场景
**副标题**：明确对象、类型、目的、输出、边界、约束、标准。不是填模板，是和AI对话磨到清晰
**顶部通栏卡**："任务定义 = 对象（推什么课）+ 类型（文案/复盘）+ 目的（引导领课）+ 输出（格式/字数）+ 边界（不能说什么）+ 约束（违禁词/风格）+ 标准（可直接下发）"
**布局**：左右双栏对话（各4轮）
- **左栏（1-2轮）**：
  - 第1轮："帮我写条短视频文案" → AI空泛输出
  - 第2轮：补充身份+用户画像 → AI仍偏（提到"养生"）
- **右栏（3-4轮）**：
  - 第3轮：补充约束（弱营销/120字/违禁词） → AI正确输出（五禽戏文案）
  - 第4轮：运营总结SOP（身份画像→违禁词→参考定调→变量），让AI确认
  - AI确认并给出优化建议："如果变量含季节/热点，可在第③步后加一句'结合当下场景'"
- **底部卡**："🎯 第4轮终点：不是产出一条文案，是磨出属于你自己的AI协作SOP"

## 第12页：Step1 延伸 — 方法论打磨对话

**标题**：Step1 延伸 — 方法论打磨对话
**副标题**：不知道从何开始？两种方式：主动补充背景信息，或让AI反问你
**布局**：左右双栏对话（共5轮）
- **左栏（1-2轮）**：
  - 运营："我不知道该怎么和AI协作，每次写文案都很乱"
  - AI反问1："你负责什么业务？日常和AI协作的具体场景是什么？"

## CSS 组件速查（复用规范）

### 卡片类
- `.card`：通用白色卡片
- `.card-pink / .card-green / .card-yellow / .card-orange / .card-red`：彩色卡片
- `.big-card-green / .big-card-orange`：大彩色卡片（用于双栏对比）
- `.sub-card`：白色内嵌小卡片（用于大卡片内部列表）

### 对话类
- `.chat-user`：用户气泡（右对齐，粉色）
- `.chat-ai`：AI气泡（左对齐，白色灰边）
- `.chat-ai.bad`：AI错误输出（红边红底）
- `.chat-ai.good`：AI正确输出（绿边绿底）
- `.chat-ai.large`：重点AI输出（红粗边框）
- `.chat-label`：气泡上方标签

### 身份/文件类
- `.id-card`：人物身份卡（顶部📎回形针装饰）
- `.id-avatar`：64px大头像emoji
- `.file-card`：文件形卡片（左上角圆形编号角标，用 data-num 属性）

### 其他
- `.formula-box`：公式块（红字白底红边）
- `.grid-3x2`：3x2网格布局
- `.checklist`：带 ☐ 前缀的清单
- `.tag-row + .tag-item`：底部标签行
- `.badge-green / .badge-red / .badge-orange`：小徽章
