# AI生成PPT提示词

> 适用工具：Gamma / 美图AI PPT / 百度文库AI / 讯飞智文 等
> 输出要求：每页内容完整，可直接用于2小时培训演讲

---

## 完整提示词（直接复制使用）

```
请为我生成一套10页的PPT，用于企业内部AI赋能培训，面向私域运营团队（中老年在线教育行业）。

## 品牌视觉风格要求
- 整体风格：简洁温暖、专业但不冰冷，适合中老年教育行业
- 配色方案：
  - 主色调：珊瑚红到暖粉色的渐变（#FF6B6B → #FF9E9E）
  - 背景色：纯白色，左侧可带有极淡的粉色圆形渐变光晕（透明度10%）
  - 文字色：深灰色（#333333），标题可用品牌红色（#E53935）
  - 强调色：暖橙色（#FF8A65）用于重点标注
- 底部设计：每一页底部固定一条红色到粉色的渐变横条，高度约页面8%
- 品牌标识：每页左下角放置"兴趣岛"品牌名 + "名师更多·课程更全"标语，白色字体置于渐变横条上
- 装饰元素：右上角可放置两个小红点作为品牌记忆点
- 字体要求：标题用粗体无衬线字体（如思源黑体 Bold），正文用常规无衬线字体，中文排版舒适、字间距适中
- 留白：大量留白，每页不超过6个要点，避免信息拥挤

## 页面结构（共10页）

### 第1页：封面
- 标题：AI赋能实战培训 —— 让AI帮你干活
- 副标题：私域运营团队 · 2026年5月
- 底部标注：培训时长约2小时 | 现场实操+当场产出
- 视觉：大标题居中，底部渐变条，整体简洁大气

### 第2页：开场 — 运营小李的故事
- 标题：为什么你觉得"AI不好用"？
- 内容结构：
  - 场景：运营小李每天写10条文案，每次给AI贴800字背景，AI还是跑偏
  - 长对话后AI"失忆"，把瑜伽卖点写成太极的
  - 小李觉得："AI还没我手写快"
- 核心结论：问题不在AI，在"每次都要重新教AI你是谁"
- 视觉：左侧放小李的故事摘要，右侧放一个"❌ AI失忆了"的示意图

### 第3页：AI能做什么 / 不能做什么
- 标题：AI是"高效执行员"，不是"创意总监"
- 左栏（绿色边框）：AI能做的3件事
  1. 按你定义的框架输出文案
  2. 帮你检查违禁词
  3. 基于数据做分析和复盘
- 右栏（橙色边框）：AI不能做的2件事
  1. 替代你想出一个新的广告位联动主题
  2. 凭空创作打动用户的"感觉"
- 底部金句：策略靠人，执行靠AI

### 第4页：今天要解决的3个问题
- 标题：今天培训完，你能带走什么？
- 3个核心问题（用数字圆圈标注）：
  1. 怎么让AI记住你的需求？→ 系统模板
  2. 怎么让AI不胡说？→ 输出约束
  3. 怎么让AI产出不重复？→ 角度库
- 底部补充：每人产出一份「个人系统模板」+ 养成每周五数据复盘的习惯

### 第5页：核心公式 — 怎么和AI说话
- 标题：一条好文案，从"会说话"开始
- 核心公式（大字突出）：你是谁 + 做什么 + 输入什么 + 输出格式
- 对比案例（左右两栏）：
  - 左栏（灰色背景，标❌）："帮我写一条推销课程的文案" → 输出空泛、千篇一律
  - 右栏（粉色背景，标✓）："你是中老年课程资深运营，用户是50-60岁已购八段锦人群，现在要推五禽戏体验课，请输出3-4段式弱营销文案，120字以内，带emoji，突出腰背痛点" → 精准可用
- 底部：关键差异 = 身份 + 画像 + 动作 + 要求 + 违禁词 + 框架

### 第6页：系统模板6要素
- 标题：让AI记住你 —— 系统模板6要素
- 6个要素用卡片式布局（2行3列或1列6行）：
  1. 【身份】你是谁
  2. 【用户画像】不变的用户特征
  3. 【动作】你每次让AI做什么
  4. 【输出要求】固定的格式约束
  5. 【违禁词清单】固定不能出现的词
  6. 【参考框架/示例】文案结构或复盘结构
- 金句：把不变的信息存起来，每次只改变量

### 第7页：加载方式3选1
- 标题：3种方式，让模板随叫随到
- 三栏对比：
  - 方式A（推荐）：DeepSeek「技能」功能 —— 预设为技能，每次新建对话自动加载
  - 方式B（备选）：快捷短语/文本替换 —— 手机/电脑一键粘贴
  - 方式C（保底）：备忘录/飞书文档 —— 复制粘贴，零门槛
- 底部提示：推荐方式A，一劳永逸

### 第8页：4个常见问题与解决方案
- 标题：AI失忆？胡说？重复？4招解决
- 表格布局（4行3列）：
  | 问题 | 真实场景 | 解决方案 |
  | AI失忆 | 写了10轮后，AI忘记不能出现"健康""养生" | 每次新对话先加载模板；10轮后开新对话 |
  | AI胡说 | AI突然推荐了一个不存在的课程 | "如果不确定，写'不确定'"；输出后自检违禁词 |
  | 千篇一律 | 连写5条文案，AI都是"腰酸背痛"开头 | 角度库法：悬疑类/互动类/大众兴趣类轮换 |
  | 不会纠正 | AI理解偏差，运营不知道怎么说 | "不对，我不是问A，而是问B""换一个方向" |

### 第9页：实战演练 — 现场产出你的模板
- 标题：45分钟实战 —— 做出你的专属模板
- 三步骤流程图（横向箭头）：
  - 步骤1（15分钟）：制作个人系统模板 → 确定任务（文案/复盘/生图）→ 填写6要素 → 选择加载方式
  - 步骤2（15分钟）：双轨实操二选一 → 轨道A：文案攥写 / 轨道B：数据复盘
  - 步骤3（15分钟）：分享点评 → 抽3-4人展示 → 现场点评
- 底部备注：每人需提交1份《个人系统模板》+ 1份实操产出

### 第10页：总结 — 带走什么 & 下一步
- 标题：今天学了4件事，5月就这么做
- 4件事回顾（数字列表）：
  1. 系统模板 → 解决AI失忆
  2. 输出约束 → 解决AI幻觉
  3. 纠正话术 → 解决AI跑偏
  4. 数据复盘 → 形成习惯（每周五固定30分钟）
- 5月使用计划（小字）：
  - 每天：写文案前先加载系统模板
  - 每周五：AI数据复盘
  - 每周：迭代1次模板
  - 月底：提交模板终版 + 复盘报告
- 工具推荐（底部小字）：DeepSeek「技能」| Gemini（安全翻墙）| 豆包生图 | Claude Code
- 结束语：AI不是替代你思考，是把你从"重复交代背景"中解放出来
```

## 使用建议

| AI工具 | 操作建议 |
|:---|:---|
| **Gamma** | 直接粘贴完整提示词，选择"简洁"主题，手动调整底部渐变条和品牌标识 |
| **美图AI PPT** | 粘贴完整提示词，生成后手动添加底部红色渐变条和兴趣岛logo |
| **百度文库AI** | 逐页使用分页面提示词，更易控制单页内容密度 |
| **WPS AI** | 使用完整提示词生成大纲，再逐页细化排版 |

**生成后必做的人工调整**：
1. 每页底部添加红色到粉色渐变横条
2. 左下角添加"兴趣岛 | 名师更多·课程更全"
3. 右上角添加两个小红点装饰
4. 检查字体大小（标题≥32pt，正文≥18pt，确保投影清晰）
